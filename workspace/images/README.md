# General JaiDee images

Any JaiDee image that is **not** published on the website goes here.

| Folder | What goes in it |
|---|---|
| `installs/` | Raw job-site photos — before/after, on-site work |
| `installs/villa-frames/` | Frame grabs pulled from villa install footage |
| `products/` | Film rolls, packaging, product close-ups |
| `marketing/` | Posters, ad creative, catalogue artwork, print files |
| `team/` | Team, shop, van, behind-the-scenes |
| `social-exports/` | Finished graphics exported for IG / FB / LINE |

Drop files straight in — no naming rules. Nothing here is deployed.

**If an image is going ON the website, it does not belong here.**
Put it in `/images/<category>/` at the repo root instead.
